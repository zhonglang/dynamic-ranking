# 📊 动态排行榜生成器 (Dynamic Ranking Generator)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Technology: Canvas](https://img.shields.io/badge/Technology-Canvas-blue.svg)](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API)
[![Export: MediaRecorder](https://img.shields.io/badge/Export-MediaRecorder-green.svg)](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder)

一个功能强大且易于使用的纯前端动态排行榜动画生成工具。专为短视频创作者、数据分析师和社交媒体达人设计，支持多种酷炫动画效果、深度视觉定制，以及高性能视频录制导出。

---

## ✨ 核心特性

### 1. 多元化动画系统 (10+ 动画效果)
- **挤压式 (Squeeze)**: 经典排行效果，新条目滑入并挤压已有条目。
- **淡入式 (Fade)**: 优雅的透明度渐变展示。
- **横向滑入式 (Slide)**: 从左侧动感滑入，充满现代感。
- **缩放弹跳式 (Scale)**: 中心弹出并带有弹性动画。
- **翻转卡片式 (Flip)**: 精致的 3D 翻转卡片效果。
- **升降机式 (Elevator)**: 底部弹跳升起，趣味十足。
- **上方飞入式 (Fly-In)**: 条目从上方下落并带有弹性回弹。
- **故障闪烁 (Glitch)**: 赛博朋克风格的色彩分离与位置抖动。
- **扫描光束 (Scan Beam)**: 带有动态光束扫描的条形图填充动画。
- **波动入场 (Wave)**: 流畅的波浪起伏进场效果。

### 2. 深度视觉定制
- **科技感背景系统（bg3，参考 OLED 赛博仪表盘 / 威胁可视化 / 终端美学）**:
  - **动态** 与 **静态** 各 **6 套**：动态含 **极光幔、全球点云、瀑布码、神经轴突、PCB 电流、OLED 干扰纹** 等；静态含 **线框地貌、星盘环、星图星座、莫尔栅、碎晶块、零一环阵** 与 **断角取景框**。
  - **火箭飞行特效**（可选）：**扁平卡通箭体**（红尖顶分面、奶油色箭体、海军蓝弯鳍、红环舷窗、深灰喷口带）+ **三叉黄/白尾焰**，风格对齐常见扁平矢量参考图（无 emoji）。
  - 背景为 **弱对比衬托主内容**，避免喧宾夺主。
  - 支持 **无主题**（纯黑底）及 **自定义背景图** 叠加与透明度调节。
- **自定义背景图**: 支持上传本地图片，提供实时透明度调节和一键清除功能。
- **智能色彩系统**: 
  - 前三名专属 **金/银/铜渐变色** 与对应勋章（🥇🥈🥉）。
  - 基于 HSL 算法自动生成具有对比度的随机渐变色。
  - 根据数值大小自动计算透明度阶梯，强化排名视觉对比。

### 3. 数值显示配置 (Value Display)
- **位置控制**: 支持“条形内”或“条形外”显示数值。
- **精确偏移**: 可自定义数值与条形图之间的像素级距离。
- **智能规则**: 支持“条形外配置仅影响非前两名”，确保头部排名视觉独特性。

### 4. 增强特效系统
- **动态烟花**: 
  - 支持 5 种图案模式（随机、圆形、心形、星形、爆炸）。
  - 10 级密度调节，支持自定义触发名次阈值。
- **红包雨特效**: 随机掉落红包、福袋、金币、元宝，带物理下落动画。
- **鲜花花瓣**: 模拟自然的飘动和旋转效果，从两侧持续生成。
- **实时弹幕**: 支持自定义内容、颜色、大小，自动滚动并循环播放。

### 5. 高性能视频导出
- **录制功能**: 基于 MediaRecorder API 实现，支持录制并导出 MP4/WebM 格式。
- **预览模式**: 提供不触发录制的纯预览模式，方便实时调试。
- **自适应分辨率**: 完美支持 9:16 短视频比例，适配主流短视频平台。

## 快速开始

可直接双击或用浏览器打开 `index.html`（`file://` 即可）。若需局域网访问或配合其他工具，也可用 HTTP 服务（例如 `python3 -m http.server 8080`）。

### 数据格式
支持 JSON 数组格式，示例如下：
```json
[
  {"name": "白羊座", "value": 856},
  {"name": "金牛座", "value": 942}
]
```

### 操作步骤
1. **输入数据**: 在左侧面板粘贴 JSON 数据或拖拽文件上传。
2. **配置样式**: 通过标签页切换，调整标题、背景、动画、特效等参数。
3. **实时预览**: 点击“预览”按钮查看当前配置的效果。
4. **导出视频**: 点击“导出视频”开始录制，动画播放完成后将自动下载视频文件。

## 🛠 技术实现

- **Canvas 2D 绘图**: 高性能条形图绘制与复杂的粒子物理模拟系统。
- **requestAnimationFrame**: 预览与绘制按显示器刷新率运行（常见约 60Hz，实际以设备为准）；**导出视频**通过 `canvas.captureStream(30)` 固定为 **30fps** 编码，与屏幕预览帧率可能不一致。
- **HSL 颜色算法**: 动态生成和谐的随机色彩方案。
- **MediaRecorder API**: 捕获 Canvas 视频流并编码为 MP4 或 WebM（具体容器/编码取决于浏览器支持）。

## 📁 文件结构

- `index.html`: 响应式页面结构与多功能配置面板（按顺序加载 `js/constants.js`、`js/dynamic-ranking.js`、`js/main.js`）。
- `css/style.css`: UI 布局与交互样式。
- `js/main.js`: 应用启动、全局错误与 `beforeunload` 清理。
- `js/dynamic-ranking.js`: 核心类 `DynamicRanking`，交互与 Canvas 动画、录制导出。
- `js/constants.js`: 背景主题、星座符号、名次数字主题等静态配置。
